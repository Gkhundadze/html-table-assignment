# პრაქტიკული დავალება — სასწავლო კვირის განრიგი

## მიზანი

შექმენი სასწავლო კვირის განრიგი HTML Table-ის გამოყენებით.

დავალების მიზანია ცხრილის სტრუქტურის შესწავლა, მისი ძირითადი HTML ელემენტების სწორად გამოყენება და მონაცემების მოწესრიგებულად წარმოდგენა.

## 1. HTML სტრუქტურა

შექმენი ცხრილი, რომელიც ასახავს სასწავლო კვირის განრიგს.

ცხრილში უნდა იყოს შემდეგი სვეტები:

- დღე
- საგანი
- დაწყების დრო
- დასრულების დრო
- ლექტორი

შეავსე ცხრილი მინიმუმ 5 დღის მონაცემებით.

## 2. ცხრილის სტრუქტურული ელემენტები

გამოიყენე შემდეგი HTML თეგები:

- `table` — ცხრილის მთავარი კონტეინერი.
- `caption` — ცხრილის სათაური.
- `thead` — ცხრილის სათაურის ნაწილი.
- `tbody` — ცხრილის ძირითადი მონაცემები.
- `tr` — ცხრილის მწკრივი.
- `th` — სათაურის უჯრა.
- `td` — მონაცემის უჯრა.

ეცადე, თითოეული თეგი დანიშნულებისამებრ გამოიყენო.

## 3. CSS სტილიზაცია

დაამატე ცხრილს მარტივი ვიზუალური სტილი.

მოთხოვნები:

- ცხრილი უნდა იყოს განთავსებული გვერდის ცენტრში.
- სათაურის მწკრივს ჰქონდეს განსხვავებული ფონის ფერი.
- მონაცემების უჯრებს ჰქონდეს საზღვრები.
- ტექსტი სწორად უნდა იყოს განლაგებული უჯრებში.
- გამოიყენე `padding` უჯრებს შორის სივრცის შესაქმნელად.
- გამოიყენე `text-align` ტექსტის გასასწორებლად.

## 4. დამატებითი მოთხოვნა

გამოიყენე `colspan` ან `rowspan` ერთ-ერთი მწკრივის ან სვეტის გასაერთიანებლად.

მაგალითად, შეგიძლია დაამატო მწკრივი, რომელიც მიუთითებს, რომ კონკრეტულ დღეს ლექციები არ ტარდება.

## ჩაბარების პირობები

- პროექტი უნდა შეიცავდეს HTML და CSS ფაილებს.
- ცხრილი უნდა იყოს აგებული სწორი HTML სტრუქტურით.
- ყველა სათაური და მონაცემი შესაბამის უჯრაში უნდა იყოს მოთავსებული.
- CSS უნდა იყოს ცალკე ფაილში.
- ვიზუალური გაფორმება უნდა იყოს მარტივი და მოწესრიგებული.

**შენიშვნა:** ამ დავალებაში მთავარი ყურადღება დაუთმე HTML Table-ის სტრუქტურას. არ არის საჭირო რთული დიზაინი ან დამატებითი ფუნქციონალი.
